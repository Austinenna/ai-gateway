# 任务内的单次调用详情

在「请求记录 → 按任务 → 调用过程」点击任意一行，使用居中浮层展示该次调用。任务列表与任务详情继续保留在下面，关闭后保留原页签、列表滚动位置，并恢复到打开窗口的按钮焦点。

- 浮层包含原有「消息 / 响应详情 / 原始数据 / 性能与用量」四个页签，原始数据仍精确复制，复制成功或失败在浮层内提示。
- 顶部显示「第 n / 总数 次调用」，使用「上一个调用 / 下一个调用」按开始顺序浏览当前任务的主／子代理调用；首尾按钮禁用，不跨任务。
- 切换调用保留当前详情页签，并将浮层正文滚动到顶部。快速切换时，旧请求的延迟响应不能覆盖当前选择；读取失败可重试。
- 导航按需补齐当前任务的分页摘要，点击任务概览中的「查看请求 / 查看响应」也使用同一浮层，包括目标调用在第一页之外的情况。补齐摘要不会展开背景列表的分页；完整正文只读取当前选择的调用，最多缓存最近 8 次。
- 进行中或正文尚未落库的调用继续轮询刷新。关闭按钮和 Esc 都可关闭浮层；手机使用接近全屏的布局，标题及前后切换按钮保持可见。

这是页面内浮层，不创建独立浏览器窗口，不改变后端记录或任务分组逻辑。

验证：临时数据库、模拟请求与模拟上游，覆盖跨 100 条分页、首尾边界、背景滚动／焦点保留、页签保留、精确复制、错误重试和快速切换；桌面、390px 手机、420px 矮窗口及深色模式截图已核对。验收结果保存在 `output/task-call-dialog-qa/`。
