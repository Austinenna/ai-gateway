# 当前管理界面

更新日期：2026-09-15。现行实现采用 **A 的整体结构＋B 的请求详情页**，技术栈为 React／TypeScript＋Vite。

## 已确认并实现

- 左侧导航包含概览、请求记录、厂商连接、模型配置、项目权限。
- 请求记录采用请求列表与详情检查器，支持消息、原始数据、耗时，以及按项目、状态和关键词筛选。
- 厂商连接可配置端点与 Token；模型名称、别名、上游 ID 与所属连接均可编辑。
- 删除厂商时直接列出关联模型，可单个删除，也可确认后级联删除全部关联模型。
- 项目使用整行列表展示身份、授权模型、状态和操作；“接入信息”提供端点、Token 与完整配置复制。
- 桌面侧栏固定在窗口内，右侧工作区独立滚动，滚动边界不带动整页。窄屏保留整页滚动，操作可达。

功能与使用边界以 [运行与使用](demo.md) 为准。布局验证包含宽屏、窄屏、长名称、深色与文字放大；滚动验证覆盖滚轮、键盘、页面切换与矮窗口底部操作。
