# 价格配置与费用统计

此功能统计经过网关的 LLM 调用，无需客户端改动。范围为单次请求、项目、模型／连接及所选时间内的网关汇总；不识别业务任务，不统计外部搜索等其他服务的费用。

## 使用

在「模型配置 → 编辑 → 价格与计费」选择：

- **未配置价格**：保留用量，费用显示未知，不作为零元。
- **按 Token 计费**：选择人民币或美元，填写每百万 Token 的输入、输出单价，免费项明确填 0。可选择所有输入同价，或缓存读取／写入分别计价；未知缓存价格留空。
- **订阅／包月套餐**：记录套餐备注与来源，调用数及 Token 用量照常统计，费用汇总中单列套餐调用，不按每次请求重复分摊订阅费，不把套餐当成免费或推测剩余额度。

可保存服务商价格来源 HTTPS 链接与实际套餐／折扣备注。来源是参考链接，不会自动抓取、同步或验证价格。当前使用手工配置的固定费率，**不自动处理峰谷时段、上下文阶梯、缓存 TTL 阶梯、折扣到期或套餐超额计费**；有这些条件的连接应保留未配置，或明确按指定参考价估算并记录适用条件。公开标价不一定是实际购买价格。

表单及模型列表显示「1 万输入＋1 千输出、无缓存」参考费用，仅用于相同用量假设下比较单价，不代表不同模型完成同一任务的真实费用。

## 在哪里看

- 总览顶部显示所选范围的估算费用、完整／部分估算次数、未配价、未知用量、套餐及历史记录数量。
- 「模型表现」直接显示每个模型／连接的估算费用和统计覆盖；TTFT／TTFC 同时显示各自有效样本数。
- 「项目费用」使用同一时间与筛选范围，点击项目可筛选；模型、连接、项目、流式／非流式筛选均作用于费用。
- 请求列表、详情顶部显示本次费用状态；「性能与用量 → 费用明细」显示计费项、Token 数、单价、金额和当时的价格来源／版本。
- 不同币种分别显示，不做隐式换汇或相加。人民币与美元的两个小计不是一个统一币种的总额。

费用是估算，实际扣款以厂商账单为准。`完整估算` 表示本次配置下所需用量与价格齐全且调用完整结束，不代表已和厂商账单对账。`部分估算` 的金额只包含能确认的部分；汇总包含这些部分金额，并显示缺失覆盖情况。

## 计算口径

每项金额 = Token 数 × 每百万 Token 单价 / 1,000,000。各项估算保留到小数点后 9 位再汇总，页面最多显示 6 位，极小的正数显示 `<0.000001`。

- Chat 的缓存读取已经包含在 `prompt_tokens` 中。分别计价时，普通输入 = 总输入 − 缓存读取；不再把缓存加到总输入上。兼容 `prompt_tokens_details.cached_tokens` 与 DeepSeek 的 `prompt_cache_hit_tokens`。
- Messages 普通输入、缓存读取和缓存写入按上报类别分别计算。沿用现有 MiniMax M3 自动缓存口径，未单列的自动缓存写入不虚构计费量。
- 缓存同价时使用已知输入总量；缓存分别计价而缺少拆分或单价时只计算已知部分。明确报告为 0 的类别无需知道其单价即可确定金额为零。
- 输出采用厂商报告的输出总量；已计入的思考或工具调用 Token 不重复追加。
- 失败、中断、取消不自动视为免费。有上报用量时保留部分估算，但不宣称最终用量完整。未转发请求和本地演示排除在需估算调用之外。
- 没有价格、没有用量、只有流式初始用量、进程异常中断以及历史缺少价格快照分别处理，不能将未知静默转为 0。

## 保存与兼容

SQLite 从版本 5 升至 6，新增 `models.pricing_json`，原模型初始为空；现有凭据、权限、记录不变。管理员模型增改接口接受 `pricing`：

```json
{
  "mode": "token",
  "currency": "CNY",
  "cache_mode": "separate",
  "input_per_million": 2,
  "output_per_million": 8,
  "cache_read_per_million": 0.2,
  "cache_write_per_million": 2.5,
  "source": "https://example.com/pricing",
  "note": "示例假价格，请填写实际价格"
}
```

`updated_at` 由服务端在价格改变时生成，表示该配置的生效版本时间。界面更换所属连接或上游模型会清除旧价格，要求重新核对。旧客户端省略 `pricing` 时，同一连接与上游模型的价格保留；更换绑定时不继承。显式清除使用 `{"mode":"unconfigured"}`。

路由时读取并固定当次价格快照，完成时把 `cost` 与计费明细同时写入监控摘要及请求记录。改价、改模型、删除配置、重启均不重算已保存的费用。此前没有价格快照的旧记录标记为历史未知，不用今天的价格追算。累计范围仍从原监控采集起点开始，费用覆盖起点取决于实际配置时间。

成本信息仅通过现有管理员认证接口返回；项目调用、公开模型目录不新增价格、管理信息或请求记录暴露。模型调用请求和上游响应格式保持原样。

## 验证

测试使用临时数据库、本机模拟上游及假价格，覆盖两种协议、缓存、缺失与零、订阅、币种分开、改价期间的请求快照、筛选、历史记录、重启与旧库升级，以及价格配置和总览／请求详情的浏览器流程。截图保存在 `output/pricing-qa/`。不读取真实 Key，不调用真实厂商，不为测试填写正式库价格。
